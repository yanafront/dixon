# DIXON MOVEMENT — интерактивная демонстрация

Запуск: `python3 -m http.server 4173 --directory dist`, затем открыть http://localhost:4173.
Без сборки и установки зависимостей. Сценарная дата — 29.10.2026, город — Минск.

Работает локально: пять разделов, каталог и фильтры, карточки, создание с предпросмотром, join/leave и счётчик, сохранённое, профиль 18+, цели/интересы, опциональный dating, like/skip и touch-swipe, scripted demo match, TTL-статус, клуб, block/report, локальная moderation queue, уведомления и экспорт аналитики. localStorage хранит данные только одного браузера. Фото — внешние иллюстрации Unsplash; это не реальные участники сообщества.

Не реализовано как production: серверная Telegram auth, PostgreSQL/PostGIS, настоящая геокарта, многопользовательские мэтчи и события, загрузка пользовательских фотографий, полноценные dating preferences, доставка бот-уведомлений, Telegram chats, серверный RBAC/admin, media moderation и удаление серверных данных. Инициализация Telegram WebApp SDK не означает авторизацию. Публичный демо-интерфейс очереди не является защищённой админкой.

Архитектура, контракты, wireframes, safety/privacy, метрики и план развития описаны в соседнем `01-product-and-architecture.md`. Переход к рабочему сервису требует реализации backend по этим контрактам и предоставления bot/server/map/storage credentials через секреты. Не вводите реальные личные данные в демо.

Проверки: `node --check dist/app.js`; HTTP 200 локального сервера; браузерная проверка главной страницы и открытия события. Полные e2e, мобильное устройство и Telegram-контейнер ещё не проверены.
