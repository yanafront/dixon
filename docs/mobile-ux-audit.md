# DIXON — мобильный UX-аудит и реализация
30 октября 2026. Источник аудита: код экранов/компонентов и API-контракты. Это экспертная проверка, не исследование с пользователями и не прохождение реальных iOS/Android Telegram-сессий.

## Информационная архитектура
Сохраняем пять разделов, меняем вход и приоритет: Активности — старт; Карта — пространственный поиск; Люди — явный social discovery; Создать — самостоятельная короткая задача; Профиль — настройки/мои данные. «Найти» переименовано в «Люди», чтобы не конкурировать с поиском мероприятий. Главная маркетинговая обложка больше не первый экран после входа. Создание остаётся в нижней thumb zone, без двух конкурирующих красных CTA в навигации.

## Telegram и доступность
BackButton закрывает текущий sheet или возвращает к активностям. Обработчики снимаются при размонтировании. Высота и inset пересчитываются при изменении viewport; нижняя навигация скрывается при клавиатуре. Tap targets 44–52px, поля 16px для отсутствия автозума iOS, поддержка reduced-motion, focus-visible. Десктопная боковая панель не определяет мобильный макет. Права, возраст, блокировки и контакты по-прежнему проверяются сервером.

## Иконки
Одна локальная SVG-система без дополнительных зависимостей: карта, люди, календарь, плюс, профиль, уведомления, сохранение, like/skip, сообщения, блокировка/жалоба, фильтры, геометка, клуб, спортивная активность. Основные операции сопровождаются текстом; декоративные SVG скрыты от screen reader. Брендовый логотип сохранён.

## Проверки и границы
TypeScript и production-сборка проверяются перед публикацией. Изменения серверных сущностей не подменены локальным состоянием.
Не считать завершёнными: реальные device-проверки iOS/Android/Desktop Telegram, VoiceOver/TalkBack, высота клавиатуры на разных устройствах и интервью с новичками. Проверить 320/375/390/430px, большой системный шрифт, горизонтальную ориентацию, запрет геолокации, медленную сеть и повторное открытие.

## Оставшиеся функциональные пробелы
Сохранение профиля другого человека не поддерживается текущим API (сохранение событий работает); нужен отдельный серверный контракт и модель, а не localStorage-имитация. «Позвать на активность» сейчас переводит в выбор событий — отдельного серверного invitation-flow нет. Полностью прогрессивный onboarding с сохранением черновика, подтверждение отмены организатором события требуют следующей итерации. Эти пункты не выдаются за реализованные в текущем релизе.

Реализован стек вложенных sheets: закрытие/Telegram Back возвращает к предыдущей карточке. Блокировка человека требует отдельного подтверждения в sheet; при успехе закрывает весь стек, чтобы скрытый профиль не оставался на экране.

## 2026-10-31 — стабильная навигация и страница уведомлений

- Нижнее меню: пять одинаковых ячеек высотой 60px внутри панели 72px + safe area. Одинаковые слоты иконок 24px и подписей 12px, без переноса и особого размера центральной кнопки.
- Стартовый раздел — «Лента». Названия экранов описывают функцию, под ними короткая подсказка следующего действия. Статус видимости показывается только на карте, в людях и профиле.
- Во всём CSS приложения line-height не превышает 1 по требованию пользователя. Расстояние между блоками задаётся отступами.
- Уведомления вынесены в самостоятельный маршрут /notifications. Колокольчик и пункт профиля открывают страницу; возврат ведёт в исходный раздел. Строки сгруппированы по дате, непрочитанные выделены, есть время и переход к активности/мэтчам. При отсутствии данных отображается пояснение и действие.
- Проверки: TypeScript, production build, git diff --check. Проверка авторизованных данных на реальном устройстве в Telegram не выполнена.

- На опубликованной версии при viewport 390×844 измерены все пять кнопок меню: 60px, иконки 24px. Переход колокольчика меняет URL на /notifications. Гостевой режим требует Telegram-входа. Ограничение line-height имеет приоритет также над стилями картографической библиотеки.

## Компактная карточка активности

- Для деталей активности добавлен отдельный вариант sheet, остальные модальные окна сохраняют размеры.
- Первый экран: категория, сохранение/поделиться, заголовок, сетка даты/места/уровня/цены, организатор, краткое описание и число участников. Полный текст, параметры, список участников и служебные действия раскрываются отдельно.
- Нижний блок с количеством мест и действием участия находится вне прокручиваемой области. Для участника с чатом отображаются чат и отмена участия.
- В локальном HTML, сгенерированном из текущего компонента на тестовых данных с длинным названием места и описанием, проверены 320×568 и 390×844. На 320×568 закрытая карточка имеет высоту 487px, не требует прокрутки; нижняя граница CTA — 552px. После раскрытия длинного текста прокручивается содержимое, CTA остаётся на экране. Горизонтального переполнения нет на обоих размерах.
- TypeScript и production build проходят. Реальная отправка join/save не выполнялась в ходе визуальной проверки.
